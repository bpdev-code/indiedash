# INDIEDASH — プロダクト構想書

## 一言で言うと

個人開発者が複数アプリの収益を一画面で管理し、BuildInPublicとして公開・シェアできるダッシュボード。

---

## ターゲット

- 個人開発者（ソロ開発、インディーハッカー）
- 複数アプリを運営している、または今後増やしたい人
- BuildInPublicとしてXで発信している人

---

## 解決する課題

| 課題 | 現状 |
|------|------|
| 複数アプリの収益をひとつで見たい | Baremetrics等は1プロダクト前提 |
| 毎月Xにシェアするのが面倒 | 手動でスクショ・テキスト作成 |
| 既存ツールが高すぎる | Baremetrics $129/月〜、個人には重い |
| 日本語対応ツールがない | 競合は全員英語 |

## 機能一覧

### 無料プラン
- プロジェクト登録（最大3件）
- MRR手動入力 + **Stripe連携（1プロダクトのみ）**
- グラフ表示（6ヶ月）
- 月次レポートテキスト生成
- **公開ダッシュボードURL**（`indiedash.app/public/yourname`、「Powered by INDIEDASH」バッジ付き）
- MRR未入力時のリマインダー通知

### 有料プラン（¥480/月）
- プロジェクト無制限
- Stripe連携（無制限）
- 公開ダッシュボードURL（バッジなし）
- **Xシェア用OGP画像生成**
- グラフ表示（全期間）

## 核心機能：公開ダッシュボードURL

### 何ができるか

`indiedash.app/public/takumi` を公開すると、誰でもそのダッシュボードを見られる。

XにURLを貼るとOGP画像カードが自動展開：

```
┌─────────────────────────────┐
│ INDIEDASH  /takumi          │
│                             │
│ MRR  ¥24,500               │
│                             │
│ ● 釣り船予約  ¥9,800       │
│ ● 寺院管理   ¥14,700       │
│                             │
│ indiedash.app               │
└─────────────────────────────┘
```

### なぜ最強のマーケティングになるか

- ユーザーがシェアするたびにINDIEDASHが露出する
- 無料ユーザーのシェアにも「Powered by INDIEDASH」バッジが入り、バイラルが無料段階から回る
- リンクを踏んだ人がUIを直接体験 → サインアップ
- **プロダクト自体がマーケティング**になるPLG設計

### プライバシー設定（2段階）

| モード | 表示内容 |
|--------|---------|
| フル公開 | MRR・プロジェクト名・グラフ全部 |
| 完全非公開 | URLにアクセスしても404 |

## プロジェクトステータス

| ステータス | 意味 |
|-----------|------|
| `idea` | 構想中 |
| `dev` | 開発中 |
| `live` | リリース済み・稼働中 |
| `archived` | 終了・休止 |

> `archived` は公開ダッシュボードに表示しない。削除せず履歴として保持。

## 成長戦略

```
ユーザーがXにシェア（無料ユーザーもバッジ付きでシェア）
  → OGP画像がタイムラインに流れる
    → 「これ何？」でリンクを踏む
      → 公開ダッシュボードを体験
        → 「自分も作りたい」でサインアップ
          → また誰かがシェア → 繰り返し
```

- Product Huntに英語でローンチ → 海外個人開発者も狙える
- 日本の個人開発コミュニティ（Xの#個人開発タグ）に先行リリース

## 技術スタック

- **Frontend**: Next.js + Tailwind
- **Backend**: Supabase（Auth・DB・RLS）
- **Deploy**: Vercel
- **OGP画像**: @vercel/og（Edge Runtime）
- **決済**: Stripe

---
